# ABC 樂譜

在電腦和手機的 Tau 文件裡用 ABC 記譜法寫樂譜，即時預覽五線譜。樂譜隨文件一起儲存，自動跟隨 Tau 的淺色與深色主題顯示。

## 開始使用

1. 在外掛中心安裝並啟用「ABC 樂譜」，然後完全關閉並重新開啟 Tau。
2. 開啟或建立文件進入編輯狀態，輸入 `/` 或點擊插入選單（`+`），搜尋「樂譜」或 `abc`，選擇「音樂標註」插入樂譜區塊。
3. 點擊樂譜區塊的原始碼編輯入口，輸入 ABC 記譜內容並點擊「儲存」，五線譜預覽會隨文件一併儲存。

可以把下面的範例貼到原始碼編輯器裡試試看：

```abc
X:1
T:練習曲
M:4/4
L:1/4
K:C
C D E F | G A B c |
```

## 常見問題

**能播放聲音或匯出 MIDI 嗎？** 不能。這個外掛負責在文件裡撰寫與顯示五線譜，不提供音訊播放或 MIDI 匯出。

**手機上也能用嗎？** 可以，電腦、Android 和 iOS 都能插入、編輯和預覽樂譜。

**停用外掛後，文件裡的樂譜會不見嗎？** 不會。樂譜原始碼一直儲存在文件裡，重新啟用並重新啟動 Tau 後照常顯示。

## 小提醒

- 安裝、啟用、停用或更新外掛後，請完全關閉並重新開啟 Tau 才會生效。
