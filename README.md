# ABC 乐谱

在电脑和手机的 Tau 文档里用 ABC 记谱法写乐谱，实时预览五线谱。乐谱随文档一起保存，自动跟随 Tau 的浅色与深色主题显示。

## 开始使用

1. 在插件中心安装并启用「ABC 乐谱」，然后完全关闭并重新打开 Tau。
2. 打开或新建文档进入编辑状态，输入 `/` 或点击插入菜单（`+`），搜索「乐谱」或 `abc`，选择「音乐标注」插入乐谱块。
3. 点击乐谱块的源码编辑入口，输入 ABC 记谱内容并点击「保存」，五线谱预览会随文档一并保存。

可以把下面的示例粘贴到源码编辑器里试一试：

```abc
X:1
T:练习曲
M:4/4
L:1/4
K:C
C D E F | G A B c |
```

## 常见问题

**能播放声音或导出 MIDI 吗？** 不能。这个插件负责在文档里编写与显示五线谱，不提供音频播放或 MIDI 导出。

**手机上也能用吗？** 可以，电脑、Android 和 iOS 都能插入、编辑和预览乐谱。

**停用插件后，文档里的乐谱会丢吗？** 不会。乐谱源码一直保存在文档里，重新启用并重启 Tau 后照常显示。

## 小提醒

- 安装、启用、停用或更新插件后，完全关闭并重新打开 Tau 才会生效。
