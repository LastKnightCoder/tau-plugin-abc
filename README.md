# ABC 乐谱

用 ABC 记谱法在文档里写乐谱，一边写一边看五线谱。乐谱会跟着文档的主题配色，还能发布到博客、随文档导出。

## 开始使用

1. 在插件中心安装「ABC 乐谱」，再到插件页的「已安装」里打开它的开关，然后点插件页顶部提示条上的「立即重启」，重启后就能用了。
2. 在文档的插入菜单里搜「乐谱」或「abc」，插入一个乐谱块。
3. 点击乐谱就能编辑，写错的地方会给出提示。

```abc
X:1
T:练习曲
M:4/4
L:1/4
K:C
C D E F | G A B c |
```

也可以让 AI 助手帮你写谱。

## 常见问题

**能播放声音吗？** 不能。插件只负责显示乐谱，不能播放或导出 MIDI。

**导出 HTML、EPUB 时乐谱怎么办？** 会自动转成图片；万一转换失败，会保留原始谱子，内容不会丢。

**停用插件后乐谱会丢吗？** 不会。重新启用并重启 Tau 后照常显示。

**手机上为什么看不到乐谱？** 手机版和浏览器插件暂时显示不了乐谱，但内容不会丢。

## 小提醒

- 需要 Tau 0.59.0 或更高版本。
- 打开、关闭或升级这个插件后，都要重启 Tau 才会生效，插件页会提示「立即重启」。
